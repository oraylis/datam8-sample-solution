# Security Reporting

Use the central [private vulnerability-report route](https://github.com/oraylis/datam8/security/advisories/new)
or DataM8@Oraylis.de if that route is unavailable. Include component versions,
reproduction and impact; keep sensitive data out of public issues.

Follow the [central reporting guidance](https://github.com/oraylis/datam8/blob/main/SECURITY.md).
Versioned examples contain neutral placeholders and secret references only. Keep
Databricks authentication profiles, Power BI credentials, `.env` files and local
deployment state outside version control. Never add passwords, tokens or client secrets.
